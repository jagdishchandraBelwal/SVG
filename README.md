# SVG Express Services – Sample Landing Page (React)

Modern, conversion-focused landing page designed as a sample for interview / freelance discussion with SVG Express Services Pvt. Ltd.

## What’s included

- Clean React + Vite + Tailwind CSS project
- Responsive (Desktop + Mobile)
- Strong hero with dual CTAs
- Stats bar
- Service cards
- Why Us + Visibility section
- Trust / social proof
- Lead capture form (Business Enquiry)
- Professional footer

## How to run

```bash
cd svg-landing-page
npm install
npm run dev
```

Then open the URL shown in the terminal (usually http://localhost:5173).

## Build for production

```bash
npm run build
npm run preview
```

## Design notes (aligned with audit)

- Stronger primary CTA (“Get Instant Quote”)
- Clear secondary CTA
- Trust signals near the fold
- Benefit-oriented service cards
- Prominent enquiry form
- Mobile-friendly navigation & sticky feel
- Brand colours matching SVG (green + accent)
